# Riset Niche Produk Digital — Meta Ad Library Indonesia

Data iklan aktif di Meta Ad Library (negara ID) per 21 Oktober 2026.

- `report.html` — report interaktif (filter WINNING, cari pengiklan)
- `REPORT.md` — versi Markdown
- `advertisers.csv` — semua pengiklan dalam satu tabel (bisa dibuka di Excel/Sheets)
- `data/*.json` — data mentah per niche
- `build_report.py` + `template.html` — generator: `python3 build_report.py data out`
